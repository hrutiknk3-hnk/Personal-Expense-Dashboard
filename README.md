# 💰 Personal Expense & Financial Analytics Dashboard

An interactive data analytics dashboard built with Python and Streamlit to analyze personal expense patterns, spending behavior, budgets, and unusual transactions.

## 📊 Project Overview

This project transforms expense data into an interactive financial analytics dashboard.

Users can filter expenses, analyze spending patterns, track a monthly budget, identify unusual transactions, explore individual transactions, and download filtered data.

## 🚀 Features

- 📊 Interactive expense dashboard
- 💰 Monthly budget tracking
- 📈 Monthly spending analysis
- 🗂️ Category-wise spending analysis
- 🔎 Subcategory analysis
- 💳 Payment method analysis
- 📍 Location-wise spending analysis
- 📅 Day-of-week spending patterns
- 😊 Mood-based spending analysis
- 🧠 Automatic spending insights
- 🚨 Unusual spending detection
- 🔎 Transaction Explorer
- 📥 Download filtered expense data
- 🎛️ Interactive filters

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- CSV
- VS Code
- Git & GitHub
